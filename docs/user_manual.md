# Welcome to **TITAN**

Welcome to your Assistant! This guide outlines the controls you can use to interact with the overlay and capture questions or code.

There are two ways to control the assistant: **Standard Hotkeys** and **Magic Sequences**. 

---

## 1. Magic Sequences (Recommended)
Magic Sequences are the most reliable way to interact with the assistant. Simply type these characters anywhere (in any text box, editor, or window) at a normal typing speed. The assistant will detect the command, automatically delete the letters you just typed so they don't mess up your work, and execute the action.

| Type This | What It Does |
| :--- | :--- |
| **`..c`** | **Capture Code:** Scans the screen for coding questions. |
| **`..m`** | **Capture MCQ:** Scans the screen for multiple-choice questions. |
| **`..l`** | **Type Next Line:** Automatically types the next line of the generated code for you. |
| **`..h`** | **Toggle HUD:** Shows or hides the assistant window. |
| **`..t`** | **Toggle Stealth:** Enters or exits stealth mode. |
| **`..g`** | **Ghost Mode ON:** Enables Ghost Mode. |
| **`..s`** | **Ghost Mode OFF:** Disables Ghost Mode. |
| **`..q`** | **Quit:** Safely closes the assistant completely. |

*Tip: If you type `..c`, the assistant will quickly hit backspace three times to remove `..c` and then begin capturing.*

---

## 2. Standard Hotkeys
If you prefer traditional keyboard shortcuts, you can use the F-keys and Alt combinations below. *(Note: Depending on your keyboard or active software, some F-keys may conflict with system shortcuts. If they don't work, use the Magic Sequences above).*

| Keyboard Shortcut | What It Does |
| :--- | :--- |
| **`F5`** | **Capture Code:** Scans the screen for coding questions. |
| **`Alt + Y`** | **Capture MCQ:** Scans the screen for multiple-choice questions. |
| **`F6`** | **Type Next Line:** Automatically types the next line of the generated code. |
| **`F2`** | **Toggle HUD:** Shows or hides the assistant window. |
| **`F3`** | **Toggle Stealth:** Enters or exits stealth mode. |
| **`F7`** | **Ghost Mode ON:** Enables Ghost Mode. |
| **`F8`** | **Ghost Mode OFF:** Disables Ghost Mode. |
| **`Alt + T`** | **Quit:** Safely closes the assistant completely. |

---

## Getting Started: A Quick Example

1. Ensure the assistant is running in the background.
2. When a coding question is visible on your screen, simply type `..c` 
3. Wait a moment for the assistant to process the question.
4. Once the answer is ready, place your cursor where you want to write the code and type `..l` (or press `F6`) repeatedly to type out the solution line-by-line.
